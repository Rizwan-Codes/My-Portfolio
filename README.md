## My Portfolio — Frontend Developer

A modern, responsive portfolio website built to showcase my skills, featured projects, and journey as a Frontend Developer. Designed with a clean user interface, smooth animations, and a focus on user experience across different screen sizes.

## ✨ Features

- **Modern UI:** Clean, professional, and visually appealing design.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Projects Showcase:** Dedicated section to display featured projects and their details.
- **Project Details Pages:** Individual pages with project descriptions, key features, and technologies used.
- **Smooth Animations:** Subtle transitions and scroll-based animations for an engaging experience.
- **Interactive Navigation:** Navigation links with active section highlighting.
- **Mobile Navigation:** Responsive mobile menu for smaller screens.
- **Resume Download:** Downloadable CV directly from the navigation bar.
- **Contact Section:** A dedicated section for getting in touch.

## 🛠️ Tech Stack

- **React.js** — Building reusable and interactive UI components.
- **Vite** — Fast development server and build tooling.
- **Tailwind CSS** — Utility-first styling for responsive interfaces.
- **React Router DOM** — Client-side routing and project detail pages.
- **Motion for React (`motion/react`)** — Smooth UI animations and transitions.
- **JavaScript (ES6+)** — Application logic and interactivity.
- **HTML5** — Semantic page structure.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rizwan-Codes/my-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
